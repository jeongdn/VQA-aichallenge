# E시리즈 작업 정리 — Q35 학습 실험과 오답 분석 (2026-09-27 01시 기준)

> 다른 작업과 합치기 위한 정리입니다. 이 작업은 **Q35(Qwen3.5-27B) 학습 변형 실험(E1~E5, D3500)과 앙상블 오답 분석**을 맡았습니다.
> 실험 번호는 이 작업 기준입니다. 다른 작업의 E7·E8·E9와는 겹치지 않습니다. 다만 다른 작업에서 "E5"라고 부른 **애매한 문항 고해상도 재채점**은 여기 E5(LR 2e-5 × 3 epoch)와 다른 실험이라 **E10**으로 부르자고 제안했습니다.
> 실험 기록만 따로 모은 문서는 `E_series_results_0926.md`입니다.

## 0. 한눈에 보기
- **Q35 학습 방식은 더 볼 것이 없음.** 학습률·epoch·어댑터 세기·보조 손실을 바꾼 변형 19개가 모두 앙상블 순이득 −2~0이었고, 앙상블 오답 23개 중 하나도 고치지 못했음.
- **학습 데이터는 3,500문항이면 충분 (D3500).** 5,714문항으로 학습한 원래 Q35와 정확도(97.2%)도, 학습이 고친·망친 문항 수(13 / 2)도 같았음. 약 1,750문항 시점에도 같은 수준.
- **학습 효과 자체는 있음.** Q35 단독은 학습 전 96.1% → 학습 후 97.2%. 하지만 앙상블에서는 Q35의 학습을 통째로 빼도 2문항만 달라짐 (다른 멤버들이 이미 맞히고 있어서).
- **앙상블 오답은 구조가 정해져 있음.** 오답 23개 중 12개는 멤버 5개가 모두 같은 오답을 확신(0.79~1.0)하고, 라벨 오류·애매 문항이 10개. 고칠 여지는 멤버 의견이 갈린 11개(앙상블 확신도 0.46~0.73)뿐 → 남은 이득은 E7·E10처럼 애매한 문항에서 답을 고르는 방법에서 나옴.
- **이 작업에서 새로 제출할 후보는 없음.** 공개 최고는 그대로 다수결 0.97676.

## 1. 공통 기준
- **기준 앙상블 `clean4_qg_hcx`** (공개 0.97636): 가중치 1·1·1·1·2로 합친 검증 정확도 97.7% (오답 23개).

  | 멤버 | 실행 폴더 | 검증 단독 | 가중치 |
  |---|---|---|---|
  | Q35 | `q35_27b_r16_native` | 97.2 | 1 |
  | Q38 | `q38_27b_r16_native` | 96.8 | 1 |
  | GDEV | `gemma4_31b_r16_up20_dev` | 97.4 | 1 |
  | G | `gemma4_31b_r16_up20` | 97.6 | 1 |
  | HCX | `hcx32b_r16_native` | 97.0 | 2 |
- **검증셋**: train에서 정답 글자별 250개씩 뽑은 고정 1,000문항 (SEED 42, md5 `df05e4bc19d27ebceeef2570672149c2`), 해상도 up2.0.
- **판정 규칙** (결과를 보기 전에 고정, 같은 문항 비교):
  - 앙상블에서 Q35 자리만 바꿨을 때 순이득 +3 이상(새로 틀림 ≤ 고침/2)이면 채택 후보
  - +1~+2면 공개 제출로 확인
  - 0 이하면 넣지 않음
  - 중간 체크포인트는 탐색으로 보고, +3이면서 인접 체크포인트도 +1 이상일 때만 공개 확인
- **학습 공통 설정**
  - QLoRA: 4bit NF4, 비전 타워는 양자화에서 제외
  - LoRA r16 / α32 / dropout 0.05
  - 유효 배치 16 (MICRO_BS 2 × GRAD_ACCUM 8), cosine 스케줄 + warmup 5%
  - 선지 셔플 증강, 학습 해상도 native, 정답 글자 토큰에만 CE
  - G4 기준 속도: 12.3초/스텝, up2.0 평가 0.88초/문항

## 3. 분석
### 3-1. 학습 효과 (E5가 학습 전 정확도를 같은 1,000문항으로 잼)
- Q35 제로샷 96.1% → 원래 학습 97.2%: 학습이 고친 문항 13 / 망친 문항 2 / 순 +11.
- 앙상블에서 Q35를 학습 전 모델로 바꾸면 순 −2 (고침 0 / 새로 틀림 2).
- LR을 낮추면 같은 자리에 늦게 도착할 뿐임 (E5는 1.5 epoch에 97.2). 2 epoch 이후에는 학습 문항 정답률 99%로 외우기만 하고 검증은 평평함.
- 데이터 양도 1,750~3,500문항이면 효과를 다 얻음 (D3500). 다른 작업 E8의 결과(전체 데이터 재학습, 공개 −4)와도 같은 방향.

### 3-2. 앙상블 검증 오답 23개의 구조
- 14개는 멤버 5개가 모두 틀림. 그중 12개는 5개가 같은 오답을 고름 (앙상블 확신도 0.79~1.0).
- 라벨 오류·애매 목록(E_eval의 GALLERY_NOISE) 10개는 전부 오답 안에 있음. 그중 8개가 "모두 틀림"에 속함.
- 11개는 멤버 의견이 갈림 (앙상블 확신도 0.46~0.73). 앙상블 최대 확률 0.7 미만으로 거르면 28문항에 이 중 9개가 걸리고, 확신 오답은 하나도 안 걸림.
- 결론: 학습·데이터·더 큰 모델로 움직일 수 있는 오답이 거의 없음. 남은 이득은 멤버 의견이 갈린 문항에서 나옴.

### 3-3. Gemma 4 31B 제로샷 미리 보기 (Drive의 기존 파일로 계산, GPU 없이)
- 검증 앞 300문항에서 제로샷은 97.67%, 학습한 Gemma(G·GDEV)는 98.33%. 학습 모델 대비 제로샷이 G보다 1개 더 맞히고 3개 더 틀림.
- 앙상블이 틀린 6개 중 멤버가 모두 틀린 4개에서 제로샷도 같은 오답을 확률 ≈1.0으로 고름.
- 제로샷 확률은 거의 0/1 (299/300이 0.99 이상). 그래서 가중치 1짜리 멤버로 넣으면 앙상블 1·2위 차이가 1/6 미만인 문항만 바뀜.
  - 검증 1,000문항 중 해당 문항은 6개(0936, 1045, 2186, 2573, 5209, 5811)이고 오답 3, 정답 3 → 순이득 상한 +3.
  - 300문항 안에서는 0936만 고침 (+1). 나머지는 E7(Gemma 예/아니오 검증)이 건드린 문항과 같음 (E7: 0936·5209·5811 고침, 2186 새로 틀림).
- 그래서 따로 돌리지 않음. E7 공개 결과가 좋으면, 4지선다 제로샷을 test의 경합 문항에만 돌리는 변형을 고려 (노트북은 그때 만들기로 함).

## 4. 나왔던 제안과 결론
- **"train 6,714문항 전체에 Gemma 제로샷을 돌려 정답률을 보자" → 하지 않음.**
  - 학습 멤버들이 그중 5,714문항을 학습해서 같은 문항 비교가 안 됨.
  - 결정에 필요한 건 경합 문항 몇 개에서의 답뿐이라, 전체 정답률은 결정을 바꾸지 못함.
- **"배치 16 → 4" → 하지 않음.**
  - Adam에서 배치를 줄이면 사실상 학습률을 올리는 것과 같음. 세기를 맞추면 LR 5e-5 수준이라 E1 범위와 겹침.
  - 문항당 신호가 정답 토큰 하나라 배치 16도 이미 작은 배치임. 4로 줄이면 라벨 오류 문항 하나가 스텝을 좌우할 위험이 있음.
  - 남은 오답은 학습 방식 문제가 아님.
- **"LR 1e-4 그대로 3 epoch" → 하지 않음.** E1이 이미 2 epoch까지 확인했고, 앙상블 추세가 0 → −2였음.
- **"학습을 3,500문항으로 줄이고 검증을 키우자" → Q35 하나로만 확인 (D3500 ✅).** 실제로 검증을 3,214문항으로 키우려면 멤버 5개를 모두 다시 학습하고 test 추론까지 해야 함 (G4 약 20시간). 마감 전에는 하지 않음.
- **"양자화 없이 bf16으로 학습하면 데이터가 더 필요할까?" → 가능성 낮음.**
  - 학습하는 LoRA와 학습 목표는 그대로이고, 4bit 쪽이 양자화 오차를 메우느라 오히려 할 일이 약간 더 많음.
  - 비전 타워는 지금도 bf16임.
  - 대회 초반 A100에서 학습한 Qwen3.5-9B·Qwen3-VL-8B(노트북 규칙상 이 크기는 양자화 없이 bf16으로 학습됨)도 100~200스텝에 수렴했음.
  - bf16이 바꿀 수 있는 건 수렴 속도가 아니라 도달하는 높이(몇 문항)이고, 그것도 Q35 변형이라 앙상블을 바꿀 가능성이 낮아 보류.

## 8. 발표·최종 문서에 쓸 만한 교훈
- **검증셋이 작았음.** 1,000문항(오답 23개)으로는 ±3문항 차이를 우연과 구별하기 어려웠음. 학습은 3,500문항이면 충분했으므로, 절반을 검증에 쓰거나 2-fold 교차 예측(반씩 나눠 두 번 학습하고 서로의 절반을 예측)으로 6,714문항 전체를 검증에 쓰는 설계가 나았음.
- **같은 문항 비교와 사전 판정 규칙이 효과가 있었음.** 단독으로는 좋아 보인 변형(E4 aux20 97.6%)을 앙상블 기준으로 걸러냈고, 공개 점수만 보고 채택했다가 떨어지는 일(E8)을 줄였음.
- **단독 성능 향상이 곧 앙상블 향상은 아님.** 멤버들이 같은 문항을 확신하며 틀리는 구조와 라벨 노이즈가 천장을 정함. 이득은 의견이 갈리는 문항을 어떻게 판정하느냐에서 나옴.
