## E20 — 불확실 문항 교차 검증 (`e20_xcheck_122b.ipynb`, G4 새 런타임)
- **기반**: zs122b_vllm.ipynb의 설치·데이터·분할·이미지 크기·모델 받기·vLLM 로드 셀을 그대로 쓴다(G4에서 실제로 돌아간 것). 조합 다시 만들기는 E7-b와 같다.
- **대상**: ea0e9f에서 1·2위 차 < τ인 문항이다.
  - 검증은 τ < 0.8까지 채점한다(참고 표용, 실제 약 59문항).
  - test는 τ < 0.5만 채점한다(241문항).
- **프롬프트** (한국어): 이미지 + 질문 + 보기 + 교차 검증 지시문
  - 조합 1·2위 보기를 "모델 A의 답 / 모델 B의 답"으로 넣는다. 배정은 문항 id 해시로 무작위다.
  - 지시: 이미지 글자를 정확히 읽고, 근거를 교차 검증하고, 착각 패턴을 배제하고, 단계별로 결론을 낸다. 마지막 줄은 `정답: (x)`.
  - system: "당신은 이미지 속 글자와 내용을 꼼꼼히 확인해 객관식 문제의 정답을 판정하는 검증자입니다."
- **생성**: 문항당 표본 5개(vLLM `n=5`, 문항별 시드). 설정은 T 0.7 · top_p 0.8 · top_k 20, 최대 1,200토큰, 생각 끔.
  - 마지막 `정답:`을 읽는다. 생각 모드를 켜면 `</think>` 뒤만 읽는다.
  - 답을 읽은 표본이 3개 미만이면 그 문항은 섞지 않는다.
- **사전 기준 (결과 전에 고정)**
  - 1차 가설: τ 0.5, α 0.5 → (1−α)·p조합 + α·q투표.
    - 효과: 투표 차가 조합의 1·2위 차보다 클 때만 답이 바뀐다.
  - 판정: 검증 순이득 ≥ +3 채택, +1~+2 공개 1회 확인, 0 이하 불채택. test는 순이득 ≥ +1일 때 자동으로 돈다.
- **결과 파일**: `vqa_runs/e20_xcheck_q35_122b/`
  - 생성 기록: `xc_val__up2.0.jsonl`, `xc_test__up2.0.jsonl` (표본마다 글자·전문)
  - 후보: `submission_e20_ea0e9f_t05_a05.csv` + 설정 JSON. 저장한 생성 파일만으로 다시 섞어 같은 답인지 확인한다.
- **점검 (CPU)**: 가짜 vLLM에 생성 모드를 더하고(인자는 실제 0.30.0 목록과 대조), 실제 5.17 Qwen3VLProcessor로 7개 시나리오를 돌려 모두 통과했다.
  - 채택: 설계한 고침 8 · 새로 틀림 2 = 독립 계산. 표본 부족 문항은 안 섞이고, test 후보 답도 설계와 같다.
  - 불채택 → test 생략.
  - 중단 → 새 세션에서 이어하기. 반쯤 쓴 줄은 다음 줄과 섞이지 않는다.
  - 생각 모드: `</think>` 뒤 답만 읽는다.
  - 형식을 안 지키면 첫 묶음에서 멈춘다.
