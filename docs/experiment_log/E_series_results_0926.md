## 학습 효과 (E5의 학습 전 측정, 같은 1,000문항)
- Q35 제로샷 96.1% → 원래 학습 후 97.2%: 학습이 고친 문항 13 / 망친 문항 2 / 순 +11.
- 앙상블에서 Q35를 학습 전 모델로 바꿔도 순 −2 (고침 0 / 새로 틀림 2).
- 해석: 학습은 모델 단독으로는 분명히 도움이 되지만(+1.1%p), 앙상블에서는 다른 멤버들이 이미 대부분을 맞히고 있어 한 멤버의 학습 방식 차이가 거의 드러나지 않음.
- LR을 낮추면 같은 정확도에 더 늦게 도달할 뿐 (E5는 1.5 epoch에 97.2 도달), 더 오래 학습해도 올라가지 않음 (2 epoch 이후 학습 문항 정답률 99%, 검증은 평평).

## 학습 데이터 양 (D3500, 2026-09-27)
- 기존 학습 5,714문항 중 3,500문항(시드 2026, md5 `97969b6c…`)만으로 원래와 같은 레시피로 학습.
- 기존 검증 1,000문항: 0.5 epoch(약 1,750문항) 97.3%, 1 epoch(약 3,500문항) 97.2% — 원래 Q35(5,714문항) 97.2%와 같음.
- 학습 전 대비: 3,500문항 모델 13/2/+11 = 원래 Q35와 똑같은 학습 효과. 1,750문항 시점도 17/5/+12.
- 원래 Q35와 답이 다른 문항 9개 (4개 고침 / 4개 새로 틀림 / 1개는 둘 다 틀림).
- 결론: Q35의 학습 효과는 1,750~3,500문항이면 다 얻어짐. 데이터를 더 넣어도 늘지 않음 (E8 전체 데이터 재학습 공개 −4와도 일치). 학습에서 뺀 2,214문항은 판정과 무관한 절대 정확도 참고용.

## 결론
- Q35 학습 방식(학습률·epoch·어댑터 세기·보조 손실)과 학습 데이터 양은 더 볼 것이 없음 → 이 방향은 닫음.
